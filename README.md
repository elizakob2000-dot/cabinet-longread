# Личный кабинет для улучшения клиентского опыта

Одностраничный лонгрид: концепция единого личного кабинета для клиентов рекламного агентства.
Автор: Кобяшева Елизавета, 2026.

Сайт статический: чистые HTML, CSS и JavaScript, без сборки и зависимостей.

## Что внутри

```
index.html            страница
favicon.svg           значок вкладки
assets/
  css/                tokens (цвета, шрифты, отступы), base, header, sections, cabinet
  js/                 media (видеофон), reveal, counter, nav, cabinet (сцена с прокруткой)
  fonts/              Manrope и Cormorant Garamond (woff2, кириллица и латиница)
  video/              фоновое видео (десктоп и мобильная версии) и постер
.github/workflows/    автоматическая публикация на GitHub Pages
docs/PUBLISH.md       пошаговая инструкция по публикации и обновлению
```

## Посмотреть локально

Откройте `index.html` в браузере. Все пути относительные, поэтому сайт работает и из папки, и по адресу `https://USERNAME.github.io/REPOSITORY/`.

## Дизайн

Направление «маркер и бумага»: бумага, графитовая «ночь» и один акцент, лаймовый маркер, который подсвечивает главное. Цвета, шрифты и отступы заданы токенами в `assets/css/tokens.css`. Тёмная тема включается автоматически по настройкам системы.

Что сохранено из исходной версии: видеофон (с лёгкой версией для телефонов), подсветка текущего раздела, счётчик, сцена «вкладки собираются в кабинет», подсветка зон кабинета тремя плюсами, режим `prefers-reduced-motion`, запасной вариант без закрепления при прокрутке.

## Публикация

Смотрите [docs/PUBLISH.md](docs/PUBLISH.md). Коротко: после `git push` в ветку `main` GitHub Actions сам публикует сайт.

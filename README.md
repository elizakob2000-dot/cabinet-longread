# Личный кабинет для улучшения клиентского опыта

Одностраничный лонгрид: концепция единого личного кабинета для клиентов рекламного агентства.
Автор: Кобяшева Елизавета, 2026.

Сайт статический: чистые HTML, CSS и JavaScript, без сборки и зависимостей.

## Что внутри

```
index.html            страница
favicon.svg           значок вкладки
assets/
  css/                tokens (цвета, шрифты, отступы), base, header, hero, sections, cabinet
  js/                 hero (первый экран), reveal, counter, nav, cabinet (сцена с прокруткой)
  fonts/              Manrope и Cormorant Garamond (woff2, кириллица и латиница)
  img/                иконки первого экрана (png с прозрачным фоном)
docs/PUBLISH.md       пошаговая инструкция по публикации и обновлению
```

## Посмотреть локально

Откройте `index.html` в браузере. Все пути относительные, поэтому сайт работает и из папки, и по адресу `https://USERNAME.github.io/REPOSITORY/`.

## Дизайн

Направление «маркер и бумага»: бумага двух тонов (светлая и камень), графитовые блоки и один акцент, лаймовый маркер, который подсвечивает главное. Первый экран без видео: иконки почты, мессенджеров и таблиц лежат вразброс и схлопываются в плашку «Личный кабинет». Цвета, шрифты и отступы заданы токенами в `assets/css/tokens.css`. Тёмная тема включается автоматически по настройкам системы.

Что сохранено из исходной версии: подсветка текущего раздела, счётчик, сцена «вкладки собираются в кабинет», подсветка зон кабинета тремя плюсами, режим `prefers-reduced-motion`, запасной вариант без закрепления при прокрутке.

## Публикация

Смотрите [docs/PUBLISH.md](docs/PUBLISH.md). Коротко: GitHub Pages сам обновляет сайт, когда в ветке `main` появляются новые файлы.

# Личный кабинет для улучшения клиентского опыта

Многостраничный сайт-концепция единого личного кабинета для клиентов рекламного агентства.
Автор: Кобяшева Елизавета, 2026.

Сайт статический: чистые HTML, CSS и JavaScript, без сборки и зависимостей.

## Страницы

| Страница | Файл | Что на ней |
| --- | --- | --- |
| Главная | `index.html` | Первый экран с анимацией, идея, цитата, сцена «Всё в одном кабинете», этапы проекта, призыв оставить заявку |
| Прототип | `prototype.html` | Интерактивный кабинет клиента (проекты, этапы, утверждение макетов) и «3 плюса» |
| Внедрение | `rollout.html` | Этапы реализации и варианты внедрения. С главной видны только варианты |
| Оставить заявку | `apply.html` | Форма заявки, окно «Заявка отправлена», окно с контактами |
| Ошибка 404 | `404.html` | Страница для неверных адресов |

## Что внутри

```
index.html, prototype.html, rollout.html, apply.html, 404.html
favicon.svg           значок вкладки
assets/
  css/                tokens (цвета, шрифты, отступы), base, header, hero, sections, cabinet, pages
  js/                 hero (первый экран), reveal, road, cabinet (сцена с прокруткой), spy (подсветка боковых точек),
                      demo (прототип), form (заявка), memory (память вкладки), nav, config (настройки формы)
  fonts/              Manrope и Cormorant Garamond (woff2, кириллица и латиница)
  img/                картинки первого экрана (png с прозрачным фоном)
docs/PUBLISH.md       пошаговая инструкция по публикации и обновлению
```

## Посмотреть локально

Откройте `index.html` в браузере. Все пути относительные, поэтому сайт работает и из папки, и по адресу `https://USERNAME.github.io/REPOSITORY/`.

## Дизайн

Направление «маркер и бумага»: бумага двух тонов (светлая и камень), графитовые блоки и один акцент, лаймовый маркер, который подсвечивает главное. Первый экран без видео: почта, мессенджеры и таблицы лежат россыпью, при наведении их становится больше, и они собираются в плашку «Личный кабинет». Цвета, шрифты и отступы заданы токенами в `assets/css/tokens.css`. Тёмная тема включается автоматически по настройкам системы.

## Приём заявок

Форма на странице «Оставить заявку» отправляет данные на сервис приёма заявок, адрес которого указан в `assets/js/config.js` (параметр `formEndpoint`). Пока адрес пустой, заявки никуда не уходят: форма показывает окно с контактами для прямой связи. Как подключить сервис, написано в [docs/PUBLISH.md](docs/PUBLISH.md).

## Память вкладки

Сайт запоминает в браузере посетителя (только до закрытия вкладки, ничего не отправляется) выбранный вариант внедрения и утверждённые в прототипе макеты. Ссылка «Начать путь заново» в подвале стирает эту память.

## Публикация

Смотрите [docs/PUBLISH.md](docs/PUBLISH.md). Коротко: GitHub Pages сам обновляет сайт, когда в ветке `main` появляются новые файлы.

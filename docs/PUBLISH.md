# Как опубликовать и обновлять сайт

Инструкция для тех, кто только начал работать с GitHub.

## Как это устроено

- **GitHub** хранит ваши файлы в интернете. Хранилище называется репозиторием.
- **Git** работает на вашем компьютере: запоминает версии файлов и отправляет их на GitHub.
- **GitHub Pages** превращает файлы репозитория в сайт.
- **GitHub Actions** делает это автоматически: как только вы отправили изменения, он сам собирает и публикует сайт.

Адрес сайта: `https://USERNAME.github.io/REPOSITORY/`, где `USERNAME` это ваш логин на GitHub, а `REPOSITORY` это имя репозитория.

## Первая публикация

### 1. Установите Git
Скачайте с https://git-scm.com/download/win и установите, везде нажимая «Next». Затем закройте и снова откройте терминал (PowerShell) и проверьте:

```bash
git --version
```

### 2. Представьтесь Git
Один раз, с почтой от GitHub:

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "you@example.com"
```

### 3. Создайте репозиторий на GitHub
1. Откройте https://github.com/new
2. В поле **Repository name** впишите имя, например `cabinet-longread`.
3. Выберите **Public**. На бесплатном тарифе GitHub Pages работает только с публичными репозиториями.
4. **Не** ставьте галочки «Add a README», «.gitignore», «license»: эти файлы уже есть в проекте.
5. Нажмите **Create repository**.

### 4. Свяжите папку проекта с репозиторием
Откройте PowerShell в папке проекта и выполните по очереди (замените `USERNAME` и `REPOSITORY`):

```bash
git init -b main
```

```bash
git add .
```

```bash
git commit -m "Первая версия сайта"
```

```bash
git remote add origin https://github.com/USERNAME/REPOSITORY.git
```

```bash
git push -u origin main
```

При первой отправке откроется окно входа в GitHub: войдите и разрешите доступ.

### 5. Включите GitHub Pages
1. В репозитории откройте **Settings**, затем **Pages** в левом меню.
2. В блоке **Build and deployment** в поле **Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions** и дождитесь зелёной галочки у запуска «Публикация на GitHub Pages» (около минуты).

### 6. Проверьте результат
Откройте `https://USERNAME.github.io/REPOSITORY/`. Сайт должен загрузиться со стилями, шрифтами и видео. Если вы видите страницу без оформления или ошибку 404, смотрите раздел «Если что-то не так».

## Как обновлять сайт

Измените файлы, затем в папке проекта:

```bash
git add .
```

```bash
git commit -m "Что изменилось, одной фразой"
```

```bash
git push
```

Через минуту изменения появятся на сайте. Прогресс виден во вкладке **Actions**.

## Если что-то не так

- **В Actions красный крестик, ошибка про Pages.** Проверьте Settings, Pages, Source: должно быть **GitHub Actions**. Затем в Actions откройте упавший запуск и нажмите **Re-run all jobs**.
- **Сайт открылся без оформления.** Проверьте, что папка `assets` лежит в репозитории рядом с `index.html`, а не внутри другой папки.
- **404.** Подождите две-три минуты после первого запуска, обновите страницу. Проверьте, что адрес написан как `https://USERNAME.github.io/REPOSITORY/` с тем же регистром букв, что в имени репозитория.
- **Видео не играет на телефоне.** Включённый режим экономии заряда может блокировать автозапуск: видео стартует после первого касания экрана.

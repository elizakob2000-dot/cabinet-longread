# Как опубликовать и обновлять сайт

Инструкция для тех, кто только начал работать с GitHub.

## Как это устроено

- **GitHub** хранит ваши файлы в интернете. Хранилище называется репозиторием.
- **GitHub Pages** превращает файлы репозитория в сайт. Он следит за веткой `main` и сам обновляет сайт, когда в ней появляются новые файлы.

Адрес сайта: `https://USERNAME.github.io/REPOSITORY/`, где `USERNAME` это ваш логин на GitHub, а `REPOSITORY` это имя репозитория.

## Первая публикация

### 1. Создайте репозиторий
1. Откройте https://github.com/new
2. В поле **Repository name** впишите имя, например `cabinet-longread`.
3. Выберите **Public**. На бесплатном тарифе GitHub Pages работает только с публичными репозиториями.
4. Не ставьте галочки «Add a README», «.gitignore», «license».
5. Нажмите **Create repository**.

### 2. Загрузите файлы
1. На странице нового репозитория нажмите ссылку **uploading an existing file**.
2. Откройте папку проекта в Проводнике, нажмите **Ctrl + A** и перетащите всё в окно браузера.
3. Дождитесь окончания загрузки и нажмите зелёную кнопку **Commit changes**.

Файлы, название которых начинается с точки (`.gitignore`, `.nojekyll`), и папку `.github` таким способом загрузить может не получиться. Для сайта они не нужны.

### 3. Включите GitHub Pages
1. В репозитории откройте **Settings**, затем **Pages** в левом меню.
2. В блоке **Build and deployment** оставьте **Source**: **Deploy from a branch**.
3. В поле **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.

### 4. Проверьте результат
Через минуту откройте `https://USERNAME.github.io/REPOSITORY/`. Сайт должен загрузиться со стилями и шрифтами.

## Как обновлять сайт

### Вариант без Git: через сайт GitHub
1. Откройте репозиторий и нажмите **Add file**, затем **Upload files**.
2. Перетащите изменённые файлы или папки (файлы с тем же именем будут заменены) и нажмите **Commit changes**.
3. Через минуту изменения появятся на сайте.

Один файл можно править прямо на GitHub: откройте его и нажмите значок карандаша.

### Вариант с Git на компьютере
Установите Git (https://git-scm.com/download/win), затем один раз укажите имя и почту:

```bash
git config --global user.name "Ваше Имя"
```

```bash
git config --global user.email "you@example.com"
```

Свяжите папку с репозиторием (один раз):

```bash
git init -b main
```

```bash
git remote add origin https://github.com/USERNAME/REPOSITORY.git
```

После каждого изменения:

```bash
git add .
```

```bash
git commit -m "Что изменилось, одной фразой"
```

```bash
git push -u origin main
```

При первой отправке откроется окно входа в GitHub: войдите и нажмите **Authorize**.

## Если что-то не так

- **404.** Подождите две-три минуты после включения Pages и обновите страницу. Проверьте, что адрес написан с тем же регистром букв, что в имени репозитория.
- **Сайт открылся без оформления.** Проверьте, что папка `assets` лежит в репозитории рядом с `index.html`, а не внутри другой папки.
- **В Settings, Pages нет выбора ветки.** Репозиторий должен быть публичным и содержать хотя бы один загруженный файл.
